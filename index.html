Core Architecture

Engineered for Fair Assessment

Every component has been designed with precision to deliver a reliable, anti-cheat testing environment.

Countdown Timer Engine

Visual warning stages with automatic client-side submission when time expires, preventing overrun attempts.

Anti-Cheat Question Shuffle

Randomizes both question and option sequence per attempt to eliminate answer-key memorization between peers.

Diagnostic Answer Review

Color-coded reviews highlighting chosen vs correct answers alongside instructor notes and educational rationale.

Live Class Leaderboard

Real-time competitive podium rankings sorted by highest percentage and fastest completion time.

Domain & Email Whitelist

Instructors can restrict tests to specific student emails or an entire university domain (e.g. @au.edu.pk).

Instant Local Persistence

Zero server latency, instant response, and reliable progress saving in local browser storage.

Common Questions

Everything you need to know about taking tests on QuizHub.

Click Student Portal on the top navigation. Enter your full name and enrolled email. Once validated, your assigned tests will immediately load on your dashboard.

When the timer hits 00:00, the test freezes and automatically submits your chosen answers to the scoring engine. You are then directed to the answer review page.

This depends on the max attempt limit set by your instructor. If set to 1, attempts are locked after submission. If set to 0 (unlimited), you can retake the quiz anytime.

Instructors access the Admin Portal using their administrative credentials to configure quizzes, set duration and pass limits, and whitelist student emails.
