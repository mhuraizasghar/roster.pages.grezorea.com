Publish & Administrative Settings

Publish Quizzes to Production
  1. Click Download published.json below to export your latest quiz bank.
  2. Commit the file into your GitHub repository under data/published.json.
  3. GitHub Pages or Cloudflare automatically deploys the updated tests to all student devices worldwide.
Backup & Data Restore

Export an encrypted snapshot of quizzes, student attempts, and leaderboards to transfer between computers.

Change Admin Password

Admin password is saved in local browser storage to protect the admin console on shared classroom PCs.

Admin Guide & Controls

  1. Manage Quizzes: Create quizzes, configure duration and pass thresholds, and input questions.
  2. Enrolment Lists: Whitelist student emails or entire domains (e.g. @au.edu.pk).
  3. Review Submissions: Inspect complete question-by-question student answers and auto-submit stamps.
  4. Publishing: Export published.json and commit to git for global student distribution.
Always change the default password after initial setup under Settings.
